- # 项目介绍
	- vibe-coding-cn 是一套中文 Vibe Coding 从入门到精通教程。帮助用户通过 AI 结对编程，从想法、需求、技术方案、任务拆解到编码、测试、部署和复盘，系统地把想法变成可运行产品。
	- 老实说，我一开始也以为这又是一个 Prompt 集合仓库。GitHub 上这类东西太多了。但这个项目的 README 里自己补了一句话——“不是 Prompt 集合，而是中文 Vibe Coding 从入门到精通教程”。定位非常明确。
