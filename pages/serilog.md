- # 项目介绍
	- **Serilog** 是 .NET 生态中最流行的**结构化日志库**，以**简洁的 API** 和**强大的扩展性**著称[](https://github.com/serilog/serilog)。它由 Nicholas Blumhardt 于 2013 年创建，现已成为 .NET 开发者进行诊断日志记录的首选工具之一。
	- 它的核心贡献，是改变了 .NET 日志记录的方式——从记录“字符串”进化为记录“结构化数据”。这意味着每条日志都是一个包含丰富上下文信息的事件，而非一行单纯的文本[](https://github.com/serilog/serilog)。
	- [serilog/serilog: Simple .NET logging with fully-structured events](https://github.com/serilog/serilog)
		- [Provided Sinks · serilog/serilog Wiki](https://github.com/serilog/serilog/wiki/Provided-Sinks)
