- # 介绍
	- Microsoft Copilot Studio 是微软推出的一个低代码平台，用于构建、管理和部署 AI 智能体（Agent）与自动化工作流程。它的核心目标是让用户无需编写复杂代码，就能创建出能处理复杂对话、执行业务流程的 AI 助手。
	- ## 🏗️ 核心功能与组件
		- 你可以把它想象成一个AI应用的“开发工厂”，主要提供以下“生产原料”：
			- **智能体 (Agents)**：这是你构建的AI助手本身。它基于大语言模型（LLM），能理解自然语言、调用知识库、执行任务。你只需用自然语言描述需求，就能生成一个智能体。
			- **工作流 (Workflows)**：用于实现可预测、可重复的自动化流程。你可以用拖放式设计器来构建，它支持将AI的灵活性与传统自动化的确定性相结合[](https://ontargit.com/microsoft-copilot-studio-2026-rebuilt/)。
			- **连接器 (Connectors)**：这是智能体与外界沟通的“桥梁”。通过内置或自定义的连接器，智能体能连接到组织的各种数据源（如 SharePoint、SQL 数据库）和业务系统（如 SAP、Salesforce）。
			- **生成式 AI 功能**：平台深度集成了生成式 AI，提供了**生成式编排**（自动链接主题与动作）、**生成式回复**（基于数据源动态生成答案）和**生成式构建**（用自然语言创建和更新智能体）等能力。最新的 **“电脑操作 (Computer Use)”** 功能甚至能让智能体像人一样“看”屏幕并操作电脑。
	- ## ⚖️ 与 Microsoft 365 Copilot 的区别
		- Copilot Studio 常与 Microsoft 365 Copilot 混淆，但它们定位不同，可以这样区分：
			- **Microsoft 365 Copilot**：是一个内置于 Office 应用中的 **AI 助手**，作用是帮助个人用户提高工作效率[](https://theaiagentindex.com/compare/microsoft-365-copilot-vs-microsoft-copilot-studio)。
			- **Microsoft Copilot Studio**：是一个 **AI 开发平台**，作用是让企业构建和部署自定义的 AI 智能体[](https://theaiagentindex.com/compare/microsoft-365-copilot-vs-microsoft-copilot-studio)。
		- 简单来说，前者是**“用”AI**，后者是**“造”AI**。
		  | 特性 | Microsoft 365 Copilot | Microsoft Copilot Studio |
		  | ---- | ---- | ---- |
		  | **核心定位** | **AI 助手**，提升个人办公效率[](https://theaiagentindex.com/compare/microsoft-365-copilot-vs-microsoft-copilot-studio) | **AI 开发平台**，构建自定义智能体[](https://theaiagentindex.com/compare/microsoft-365-copilot-vs-microsoft-copilot-studio) |
		  | **目标用户** | 最终用户（知识工作者） | 制作者、IT 人员、开发者 |
		  | **主要用途** | 在 Word、Excel 等应用中辅助创作、分析 | 构建处理复杂业务流程的智能体 |
		  | **构建方式** | 开箱即用，或通过 Agent Builder 轻量定制 | 通过低代码/无代码图形界面深度定制 |
		  | **部署范围** | 个人或小团队 | 部门、整个组织或外部客户 |
		  | **典型场景** | 起草文档、总结邮件、生成报表[](https://theaiagentindex.com/compare/microsoft-365-copilot-vs-microsoft-copilot-studio) | 客服机器人、IT 支持、销售助理 |

	- ## ✨ 2026年重要更新
		- 2026年6月，微软发布了 Copilot Studio 的**重大重构版本**[](https://ontargit.com/microsoft-copilot-studio-2026-rebuilt/)，核心变化包括：
			- **全新的编排器 (Orchestrator)**：新的编排器专为处理**长周期、多步骤的复杂任务**而设计，使智能体能更可靠地遵循指令[](https://ontargit.com/microsoft-copilot-studio-2026-rebuilt/)。
			- **全新的构建界面**：创作界面被简化为**单页视图**，配置标签页从9个减少到4个，让开发过程更聚焦[](https://ontargit.com/microsoft-copilot-studio-2026-rebuilt/)。
			- **引入“技能 (Skills)”**：支持将可复用的指令集（Skills）导入或创建，甚至可以复用 GitHub Copilot 或 Claude Code 的技能[](https://ontargit.com/microsoft-copilot-studio-2026-rebuilt/)。
			- **MCP 就绪的工作流**：工作流设计器现在可以连接到支持 **MCP (Model Context Protocol)** 的第三方工具，扩展性更强[](https://ontargit.com/microsoft-copilot-studio-2026-rebuilt/)。
