- # 使用格式说明
	- 方式一：通过下面的输入来设置任务优先级。
	  ```markdown
	  /A
	  /B
	  /C
	  ```
	- background-color:: pink
	  #+BEGIN_IMPORTANT
	  任务的优先级[Priority]支持的配置只有 A/B/C 
	  优先级 A（最高）、B、C（最低）三个级别。
	  #+END_IMPORTANT
	- 方式二：通过输入 ``[#A]`` 来设置优先级。
-
- # 例子
	- DONE [#A] 最高优先级A。
	- DONE [#C] 最低优先级C。
	- DONE [#B] 中间的优先级B，注意优先级和内容之间要有空格分开。
