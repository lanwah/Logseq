- # 项目介绍
	- claude-howto-zh-cn 是一份**为中文开发者量身打造的 Claude Code 实战指南**，它把官方文档的碎片化功能整理成了一条清晰的学习路径，并贴心地考虑了中国用户常见的网络、环境、权限等实际问题。无论你是刚接触 Claude Code 的新手，还是想深入掌握其高级功能的进阶用户，都能从这个项目中找到适合自己的内容。
