- # 项目介绍
	- **ccstatusline** 是一个为 **Claude Code CLI** 设计的高度可定制的状态栏（statusline）格式化工具。它能让你在终端底部实时查看 Claude Code 会话的关键信息，如当前模型、Token 用量、Git 分支等，让你的 AI 编程体验更透明、更可控[](https://cloud.tencent.com.cn/developer/article/2670065?policyId=1004)。
