- # 项目介绍
	- **khazix-skills** 是数字生命卡兹克开源的一套 AI Skills 合集，包含了他自己每天都在用的几个实用技能。这是一套遵循 [Agent Skills](https://agentskills.io/) 开放标准的**结构化指令集**[](https://github.com/KKKKhazix/khazix-skills)，Claude Code、Codex、Qoder、Kimi Code、CodeBuddy、Cursor 等 **40 多种**支持该标准的 Agent 都可以直接安装使用[](https://github.com/KKKKhazix/khazix-skills)。
	- ## 核心技能一览
		- | 技能名称 | 一句话功能 |
		  | ---- | ---- | ---- |
		  | **leader（领导）** | 把一句模糊的想法，定义成一份清晰的**目标**，让 AI 拿着自己跑几个小时到完成[](https://github.com/KKKKhazix/khazix-skills) |
		  | **storage-analyzer（清理垃圾）** | 一句话扫描 Mac/Windows 整机磁盘，三色分级给出清理决策，网页上一键移废纸篓[](https://github.com/KKKKhazix/khazix-skills) |
		  | **aihot（AI HOT 资讯查询）** | 让 Agent 用一句话拿到 [aihot.virxact.com](https://aihot.virxact.com/) 每天的 AI HOT 日报和全部 AI 动态，**无需 API Key**[](https://github.com/KKKKhazix/khazix-skills) |
		  | **neat-freak（洁癖）** | 干完活跑一下 `/neat`，自动对齐项目文档、CLAUDE.md、Agent 记忆，并审计规则有没有被执行[](https://github.com/KKKKhazix/khazix-skills) |
		  | **hv-analysis（横纵分析法）** | 想搞懂一个产品/公司/概念是怎么回事，丢给它，给你一份**万字 PDF 研究报告**[](https://github.com/KKKKhazix/khazix-skills) |
		  | **khazix-writer（卡兹克写作）** | 装上之后，Agent 用作者本人的口吻和节奏写公众号长文 |
