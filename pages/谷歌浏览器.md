- # 开发者模式面板快捷键
	- F12 或 Ctrl + Shift + I 打开开发者模式。
	- |快捷键|说明|
	  |--|--|
	  |Ctrl + P|打开文件|
	  |Ctrl + Shift + P|运行命令|
	  |Ctrl + G|跳转到行|
	  |F5 或 CTRL + R|浏览器会先检查本地缓存。如果缓存资源未过期，就直接使用缓存，加载速度更快，但可能看不到最新内容。|
	  |CTRL + Shift + R|浏览器会无视缓存有效期，直接向服务器请求每个资源的最新版本。这能确保你看到的是绝对最新的页面，但加载速度会变慢。|
