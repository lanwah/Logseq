- # 快捷键
	- |快捷键|说明|
	  |--|--|
	  |Ctrl + Shift + P|打开命令面板|
	  |Ctrl + Shift + W|关闭当前的终端窗口|
	  |Alt + Shift + +|垂直拆分窗口|
	  |Alt + Shift + -|水平拆分窗口|
	  |Alt + 方向键|切换输入焦点|
	  |Alt + Shift + 方向键|调整当前窗口大小|
	  |Ctrl + +|增大字号|
	  |Ctrl + -|减小字号|
	  |Ctrl + 0|恢复默认字号|
	  |Alt + Enter|全屏/窗口模式切换|
