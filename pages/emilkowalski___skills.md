- # 项目介绍
	- **emilkowalski/skills** 是一套为设计师和工程师准备的 AI 技能集，旨在帮助 AI 编程助手（如 Claude Code、Cursor 等）构建出更优质、更有“品味”的用户界面[](https://github.com/emilkowalski/skills)。
	- ## 🛠️ 技能列表
		- 该项目包含多个专注于 UI 和动效设计的技能，你可以根据需要选择安装[](https://github.com/emilkowalski/skills)：
		  | 技能名称 | 功能描述 |
		  | ---- | ---- | ---- |
		  | **`emil-design-eng`** | 主技能，主要包含动效设计建议，也涵盖部分通用设计建议[](https://github.com/emilkowalski/skills)。 |
		  | **`review-animations`** | 根据预设规则，以严格的标准审查你的动画实现[](https://github.com/emilkowalski/skills)。 |
		  | **`improve-animations`** | 审计代码库中的所有动画，并生成优先级明确的、可独立执行的改进计划[](https://github.com/emilkowalski/skills)。 |
		  | **`find-animation-opportunities`** | 在 UI 中搜索适合添加动效的地方，同时指出**不应**添加动效的区域[](https://github.com/emilkowalski/skills)。 |
		  | **`animation-vocabulary`** | 提供准确的动效术语，帮助你更清晰地向 AI 描述需求，以获得更好的动画效果[](https://github.com/emilkowalski/skills)。 |
		  | **`apple-design`** | 从苹果的 WWDC 设计讲座中提炼出的界面设计与流畅动效原则，并适配到 Web 端[](https://github.com/emilkowalski/skills)。 |
		  | **`pick-ui-library`** | 帮助 AI 基于作者信任的库列表，为任务选择正确的 UI 库，避免使用被遗弃的包或自行造轮子[](https://github.com/emilkowalski/skills)。 |
		  | **`prototype`** | 根据你的描述，构建 UI 组件的多个不同版本，并提供一个切换器方便你进行对比[](https://github.com/emilkowalski/skills)。 |
