- 把Logseq发布成静态网站。
- # 发布步骤
	- ## 本地发布
		- ### 步骤 1：在 Logseq 桌面版打开图库
			- 1. 启动 Logseq 桌面版
			- 2. 打开图库目录 **`D:\Work\Docs`**
			  > 若图库已在 Logseq 中打开，跳过此步。
		- ### 步骤 2：导出为静态网站
			- 1. 点击右上角 **⋯（三个点）** 菜单
			- 2. 选择 **导出图谱 - 导出公开页**。
			- 3. 选择导出目录：**`D:\Work\Docs\out`**（建议新建 `out` 文件夹）
			  > 导出完成后，`out/` 内应包含 `index.html`、JS/CSS 资源及页面数据。
			- **发布配置说明**（当前无需改动）：
				- 给页面加 `public:: true` 可使其被导出
				- 或在 Settings → Editor 开启 "All pages public when publishing"
				- 或在 `config.edn` 设置 `:publishing/all-pages-public? true`
		- ### 步骤 3：本地预览
			- **不要**直接双击 `index.html`（资源路径会失效）。使用已安装的 `serve`：
			  ```powershell
			  cd D:\Work\Docs\out
			  serve -p 8080
			  ```
		- 浏览器访问：**http://localhost:8080**
		- 预期结果：可看到「项目打包」页面（当前唯一 public 页面）。
	- ## 常见问题
		- | 问题 | 处理 |
		  |------|------|
		  | 导出后几乎无内容 | 页面未标记 `public:: true`；当前仅「项目打包」会被导出 |
		  | 图片/附件不显示 | 必须通过 HTTP 服务器访问，不能用 file:// |
		  | 找不到 Export graph | 确保使用**桌面版**（非 Web/移动端）；菜单位于右上角 ⋯ |
		  | 每次更新都要重新导出 | 桌面版无自动监听；改完笔记后手动再 Export 一次 |
