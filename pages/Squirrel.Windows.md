- # 项目介绍
	- **Squirrel.Windows** 是一个为 Windows 桌面应用设计的**安装与自动更新框架**[](https://github.com/Squirrel/Squirrel.Windows)[](https://deepwiki.com/electron/windows-installer/4.1-squirrel.windows-overview)。它的核心理念是让 Windows 应用的安装和更新，能像 Google Chrome 浏览器一样**快速、简单且无感**[](https://github.com/Squirrel/Squirrel.Windows)。
	- 它的项目口号很直接：“**It's like ClickOnce but Works™**”（就像 ClickOnce，但能用）[](https://github.com/Squirrel/Squirrel.Windows)[](https://www.advancedinstaller.com/what-is-squirrel-framework.html)，一语道破了它旨在解决传统部署工具（如 ClickOnce）各种问题的决心。
