- # 脚本
	- ```powershell
	  // 此次排查 10086 端口占用，共用到以下命令：
	  
	  // 1. 查找占用 10086 端口的连接及 PID
	  netstat -ano | findstr :10086
	  // 2. 根据 PID 查看进程基本信息
	  // 其中 50652 是 netstat 查到的 LISTENING 状态 PID；若端口被其他进程占用，换成对应 PID 即可。
	  tasklist /FI "PID eq 50652" /V
	  // 3. 查看进程完整路径与命令行
	  Get-CimInstance Win32_Process -Filter "ProcessId=50652" | Select-Object ProcessId, Name, ExecutablePath, CommandLine | Format-List
	  // 4. 释放端口（当时仅作建议，未实际执行）
	  Stop-Process -Id 50652 -Force
	  ```
