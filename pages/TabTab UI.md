- # 项目介绍
	- **TabTab UI** 是一个基于 **Vue 3** 和 **TypeScript** 的现代化后台管理系统模板与组件库[](https://github.com/tabtab-dev/ui)。它的定位是帮助开发者快速搭建功能完善、视觉美观的后台应用。
	  该项目采用 **Monorepo** 架构进行管理[](https://github.com/tabtab-dev/ui)，主要包含两个核心应用：
		- **Admin (后台管理系统)**：一个功能完整的管理后台模板，提供了 **5 种布局模式**（如侧边栏、顶部导航、混合布局等）的实时切换，并集成了明暗主题切换、多标签页管理、国际化（中英文）和全局搜索等功能[](https://github.com/tabtab-dev/ui)。
		- **Playground (组件演示)**：用于开发和测试 UI 组件的演示环境[](https://github.com/tabtab-dev/ui)。
	- ## 🛠 技术栈与开发语言
		- 这是一个**纯前端项目**，不包含后端服务。其核心开发语言和框架如下[](https://github.com/tabtab-dev/ui)：
		  | 类别 | 技术 | 说明 |
		  | ---- | ---- | ---- |
		  | **核心框架** | **Vue 3** | 前端框架 |
		  | **开发语言** | **TypeScript** | 主要编程语言，提供类型安全[](https://github.com/tabtab-dev/ui) |
		  | **构建工具** | **Vite Plus** | 基于 Rolldown (Rust编写) 的构建工具，提供极速构建体验[](https://github.com/tabtab-dev/ui) |
		  | **样式方案** | **Tailwind CSS v4** | 原子化CSS框架[](https://github.com/tabtab-dev/ui) |
		  | **UI组件库** | shadcn-vue & Reka UI | 无头UI组件库，提供高度可定制的组件[](https://github.com/tabtab-dev/ui) |
		  | **状态管理** | **Pinia** | Vue官方推荐的状态管理库[](https://github.com/tabtab-dev/ui) |
		  | **路由管理** | **Vue Router 4** | Vue官方路由库 |
