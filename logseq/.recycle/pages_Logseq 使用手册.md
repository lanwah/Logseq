- # 功能介绍
  id:: 69d5ab67-bf15-4aa5-97f1-b5e1a8b0c062
- 软件目录下 journals，pages，logseq 三个文件夹的作用。
  id:: 69d5ab70-8537-43e7-afaa-3fcfb3c67740
  | 目录 | 作用 | 存储内容举例 |
  | ---- | ---- | ---- |
  | **`journals `** | 存放**日记 (Journal)** 类笔记，用于时间线记录[](https://blog.gitcode.com/9534517b2a33d1e3d1024197862badd9.html)。 | 如 `2026_04_08.md` 或 `2026-04-08.md`，每日自动生成[](https://zhuanlan.zhihu.com/p/370299376)。 |
  | **`pages`** | 存放**普通页面 (Page)**，用于构建系统的知识网络[](https://blog.gitcode.com/9534517b2a33d1e3d1024197862badd9.html)。 | 如 `项目管理.md` 或 `Python学习笔记.md`，由你手动创建。 |
  | **`logseq`** | 存放**应用配置**和**缓存数据**，是程序运行的"后台"[](https://blog.gitcode.com/9534517b2a33d1e3d1024197862badd9.html)。 | `config.edn` (配置文件)、`plugins` (插件文件夹) |
